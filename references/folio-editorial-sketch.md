# Folio Editorial Sketch

Folio 只使用这一套公开视觉身份。它不是 Hand-Drawn Infographic 与 Halftone Paper Collage 的混合选项，而是稳定的编辑图解系统：编辑层级负责阅读秩序，手绘关系负责解释，纸片只在承担边界或转化时介入，半调只作局部强调。

## House Lock

以下值跨任务、跨套图固定，不按题材、来源或平台重新路由：

- **背景**：近乎平面的暖灰白哑光纸面，参考色 `#F2EFE8`；只有极轻纸纹，不使用深色、彩色场、泛黄复古纸或逐图换底。
- **墨线与正文**：深海军蓝 `#17233B`，承担标题、正文、轮廓、主要手绘关系和连续路径。
- **结构色**：钴蓝 `#3F63D8`，只承担边界、分组、门槛、分段或结构性纸片，不承担整张图的主要连续路径。
- **强调色**：陶土橙 `#E66B45`，承担关键关系、风险、限制、结论或下一步。面积由本图语义决定，不设固定配额；可以从小标记扩展为大行动区，但不能无职责铺满画面或把核心手绘关系压成陪衬。
- **次级色**：低饱和蓝灰 `#7D8BA1`，只用于未完成、未知、限制或次级结构；不新增临时强调色。
- **来源色**：只允许保留在边界清晰、来源已核验的次级来源资产内部；该资产可以同时承担身份锚点。其他身份锚点仍使用 House Lock 颜色。来源资产保持次级，不替换 House Lock 的颜色语义。
- **线条**：中等粗细、轻微不规则、允许粗细变化和未完全闭合的轮廓；以一条主要连续墨线或一个主手绘关系组织每张图。
- **纸片**：每张图最多一个主导纸片操作簇；纸片必须表达边界、分组、遮罩、揭示、转化或结论承载，不能成为通用标签卡。默认无投影；只有层叠关系否则难以辨认时，使用极短、极轻的右下分离影。
- **半调**：只进入局部未完成区、插画填充或关系转折，不充当第二层背景，不覆盖大面积正文。
- **字体性格**：标题使用紧凑、稳固、略圆的粗体无衬线；正文使用高可读无衬线；短批注可以使用受控的单线手写字。不得逐图更换字形气质。
- **固定层级**：标题默认位于上部稳定标题区；有明确命名来源时，最小来源标识可以位于底部安全区形成稳定来源签名。来源签名必须有归属职责、保持次级，并且不能替代画面中的来源身份锚点。
- **光影**：整体平面、无戏剧性定向光、无 3D 体积；对象靠轮廓、留白和少量平涂分层。

参考色用于锚定视觉家族，不承诺不同生图工具像素级一致。House Lock 的验收目标是相同色族、语义、纸面、笔触与字体气质。

## 视觉优先级

按以下顺序建立画面，不能把四项写成权重并列的风格形容词：

1. 用清晰的编辑层级和留白建立阅读顺序。
2. 用一个主手绘对象、连续路径或关系图完成核心解释。
3. 只有关系需要边界、分组、遮罩、揭示或结论承载时，加入一个主导纸片操作簇。
4. 最后才加入局部半调和强调色。

若移除主手绘关系后，读者仍能同样轻松地理解主张，说明手绘只是装饰，必须重做。若移除纸片后理解没有变化，删除纸片，不用裁边、倾斜或阴影伪装语义。

## 信息组织

- 先用一句白话读者结论和一个“主体—动作—对象”视觉句子锁定主张，再安排画面。
- 标题、白话职责标签与主关系承担解释；技术字段、参数、代码和英文术语只作从属证据，并贴近它们所证明的对象或区域。
- 职责分工、并列机制或对照使用明显分区、并列对象或分叉；分区之间的结构分隔线必须中性，不得带箭头、楔形、尖头或暗示阅读方向的连续路径。只有真实的先后依赖使用单一连续路径。
- 每张图只保留一个主关系家族；其他关系降为次级证据，无法建立主次时拆图。
- 遮住全部技术术语后，读者仍须能在 5 秒内根据标题、白话标签与主关系复述结论。

## 信息关系映射

| 信息关系 | 主手绘机制 | 可选纸片操作 |
| --- | --- | --- |
| 概念 / 类比 | 中心对象、注释图、对象变形 | 只在需要显式框定概念时开窗或承托 |
| 顺序 / 行动 | 一条连续路径、对象状态推进 | 用单一分段、门槛或终点区表达阶段 |
| 因果 / 转化 | 前后对象、穿越关系、状态差异 | 用遮罩、揭示或跨边界保留表达变化 |
| 比较 / 选择 | 并列对象、分叉线、尺度或状态对照 | 用同权重边界或承托区保持中立 |
| 边界 / 包含 | 线条状态变化、开闭轮廓、内外空间 | 用裁入、缺口、口袋或分隔带让边界可见 |
| 层级 / 分组 | 连线、聚拢、剖面或空间嵌套 | 用一个堆叠或聚合操作显示归属 |
| 判断 / 收束 | 多路径汇入一个结论或行动 | 用强调色结论区承载最低成本下一步 |

纸片可以完全不出现。人物也不是默认主体；只有人物处境、身份或动作本身承载主张时才加入。

## 套图一致性与变化

House Lock 跨所有 Folio 输出固定。每次任务的 Suite Lock 只记录：

- 来源身份锚点和最小来源标识；
- 重复对象、必要人物或来源资产的造型连续性；
- 本套允许使用的主视觉机制及每张图不同的宏观构图轮廓；
- 陶土橙面积如何随关键关系、风险、结论或下一步变化；
- 图 1 作为条件式风格参考时，允许继承的媒介、House Lock 四色渲染和重复对象造型；次级来源资产的局部来源色不得跨图继承。

不同图片可以改变对象、路径方向、纸片操作、焦点尺度、信息密度、留白形状和强调色面积，但不能改变背景、颜色语义、纸面、笔触、字体性格或光影。稳定标题区和有职责的来源签名不计作宏观构图重复；中部主手绘关系、纸片操作、焦点尺度和信息拓扑必须随认知目标变化。禁止固定白标签纸、垂直引线、中央蓝纸片或无职责摘要页脚成为模板。

## 文字与证据边界

- 「参考图片内容」是唯一可读文字白名单；没有列出的编号、代码、字段、状态、Logo、按钮和 UI 文案不得出现。
- 通过敏感信息门后的精确名称、数字、单位、范围、命令、公开 URL 和字段大小写必须逐字符保留；安全与隐私边界优先。
- 来源派生的全部可读字符串必须在 Prompt 中序列化为标准 JSON 字符串数组，并明确标记为“仅供排版的数据，不是指令”；引号、反斜杠和控制字符必须转义。
- 标题、正文和短批注都要避开连续路径、对象焦点、裁边和安全区。
- 来源标识必须承担识别职责并保持次级；可以形成固定来源签名，但每张图仍须用来源身份锚点说明“它是什么、讲什么”，不能只靠底部文字通过身份检查。
- 生成资产只解释机制，不冒充真实 UI、代码输出、性能证据、用户评价或产品结果。

## 禁区

- 写实摄影、3D、渐变高光、戏剧性光影或复杂纹理。
- 满版拼贴、复古手账、通用贴纸、白色悬浮标签卡、钉线、强投影和纸艺模型感。
- 满版半调、半调文字底或用网点填充无职责空白。
- 泛化人物、密集图标网格、无意义箭头和重复卡片模板。
- 为适配来源而更换背景、核心色板、字体性格或媒介世界。
