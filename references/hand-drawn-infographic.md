# Hand-Drawn Infographic

## 核心原则

用连续手绘线条、简化形体、自由注释与克制着色降低认知负担。Hand-Drawn 是视觉语言，不是人物模式；对象、符号、空间、环境、手或人物都可以成为内容载体，是否出现人物只由主张决定。

若移除对象关系、注释、状态变化、动作或空间组织后，核心主张仍能被同样轻松地理解，说明画面机制只是装饰，必须重做。人物不计作必要机制；没有人物的手绘图完全成立。

## 关系到手绘机制的映射

| 信息关系 | 候选手绘机制 | 应更容易理解的内容 |
| --- | --- | --- |
| 概念 / 类比 | 中心对象、隐喻或注释图 | 抽象概念对应什么熟悉结构 |
| 顺序 / 行动 | 手绘路径、对象状态或必要的人物动作 | 先后步骤和状态如何推进 |
| 因果 | 前后对象、标注箭头与状态差异 | 哪个变化产生什么后果 |
| 选择 | 分叉路径、并列对象或必要的处境 | 不同选择分别意味着什么 |
| 清单 | 一个视觉区域中的少量对象与注释 | 此刻真正需要注意什么 |
| 结构 / 系统 | 手绘剖面、连接图或空间分区 | 部件如何连接、属于或相互影响 |

## 构图机制

- 用一个主对象、主关系或主场景建立第一视觉焦点。
- 优先选择最直接的内容载体：对象演示、注释图、手绘流程、空间关系或对照；只有人物处境、身份或动作本身承载主张时才加入人物。
- 让对象、符号和图标直接解释关键词、步骤或因果，不把它们当填充物。
- 用充足留白隔开标题、主体与辅助说明；每块空间只有一个信息职责。
- 有明确命名来源时，使用至少一个名称之外、且有来源依据的实体类型、材料、结构、行为或资产线索作为来源身份锚点；再使用至少两个内容解释锚点承载本图主张。规范名称由最小来源标识承担，不单独计入锚点数量；身份可以通过对象、材料、结构、阅读、批注或操作行为呈现，不能只在角落贴名称或 Logo。无明确来源时不补造身份。

## 套图一致性

共享笔触、字体性格、颜色角色、插画世界和线条密度，不共享完成后的构图模板。不同图片应根据认知目标改变主对象、注释方式、动作或状态、焦点尺度和文字—对象关系。

生图前先把这些共享项具体化为 Suite Lock：唯一背景基底及选择依据；墨线/正文、主色、辅色和强调色的语义角色及可选参考色；平涂、数字画布、白板、粉笔板或纸张等具体表面；轮廓粗细与不规则程度；固定光影；标题与正文字体性格；重复对象的造型连续性。若复用人物，再锁定发型、肤色、服装轮廓与配色、身体比例和面部/线条风格；不使用人物时无需建立人物设定。参考色只锚定视觉家族，不承诺跨工具像素一致。

每张图逐项完整重复这些固定值，只在「本图变化」中改变对象、注释、动作或状态、空间组织、构图重心和既有强调色的使用比例。不得逐图重新选背景、颜色角色、材质、重复对象或人物造型。

禁止多数图片重复“顶部标题 + 中间人物/图标网格 + 底部摘要”。人物不能作为默认主体；重复对象或人物只有在状态、动作、处境或关系随叙事推进时才可复用。

## 文字规则

- 使用与输入相同的语言，除非用户另有指定。
- 精简信息，突出关键词、核心概念与必要数字。
- 所有文字、线条和图像保持统一的手绘质感。
- 主标题可在 5 秒内完整读完；正文不贴边、不跨越对象焦点、人物面部或复杂图形。
- 「参考图片内容」是唯一可读文字白名单；不生成白名单外文字。需要精确的名称、数字、命令或 URL 时逐字符保留。

## 视觉语言

- 手绘插画、轻微不规则轮廓、平涂或受控笔刷；背景可以是清洁白/冷白、浅灰、彩色平涂、深色高对比表面或纸张，不把纸感视为默认。
- 背景与色彩由 Suite Lock 独立决定。内部至少比较三个在色温或明度上明显不同的候选，按用户指定、可核查来源视觉、平台环境、内容语气和文字对比选择；记录最终依据，单图不得重新选色。
- 未有明确依据时，不得机械使用暖米白、奶油色、羊皮纸、泛黄纸或复古纸；“手绘”本身不是选择这些背景的理由。
- 氛围轻松但不幼稚；技术主题也保持清晰和可信。
- 若主张确实需要人物，而内容涉及敏感、受保护或无法直接使用的人物形象，改用不复制具体肖像、但能承载相同叙事角色的原创替代形象。

## 禁区

- 禁止写实摄影、3D 写实物体或照片质感混入。
- 禁止密集图标、装饰性箭头、无意义贴纸和满版文字。
- 禁止仅因为选择 Hand-Drawn 就添加讲解员、产品经理、工程师或其他泛化人物。
- 禁止用著名人物形象替代事实证据或制造未经来源支持的背书。
- 禁止让文字与图形、边框、裁切线互相覆盖。
