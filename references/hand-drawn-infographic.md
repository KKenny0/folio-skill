# Hand-Drawn Cartoon Infographic

## 核心原则

用一个具体场景中的角色、对象和动作降低认知负担。核心体验是亲切、清楚、可快速扫读，不是卡通装饰越多越好。

若移除主要角色、动作或场景后，核心主张仍能被同样轻松地理解，说明场景只是装饰，必须重做。图标只能解释动作或对象，不能代替场景机制。

## 关系到场景的映射

| 信息关系 | 候选场景机制 | 应更容易理解的内容 |
| --- | --- | --- |
| 概念 / 类比 | 一个中心隐喻场景 | 抽象概念对应什么熟悉经验 |
| 顺序 / 行动 | 角色沿动作推进 | 谁先做什么、下一步是什么 |
| 因果 | 动作前后的状态变化 | 哪个动作产生什么后果 |
| 选择 | 两种处境或行动结果 | 不同选择分别意味着什么 |
| 清单 | 一个场景中的少量行动线索 | 此刻真正需要注意什么 |

## 构图机制

- 用一个主概念或主场景建立第一视觉焦点。
- 只加入少量简单卡通人物、图标或具辨识度的公共人物替代形象。
- 让图标直接解释关键词、步骤或因果，不把图标当填充物。
- 用充足留白隔开标题、主体与辅助说明；每块空间只有一个信息职责。
- 有明确命名来源时，使用至少一个名称之外、且有来源依据的实体类型、材料、结构、行为或资产线索作为来源身份锚点；再使用至少两个内容解释锚点承载本图主张。规范名称由最小来源标识承担，不单独计入锚点数量；身份可以通过阅读、批注、操作来源实体等场景动作呈现，不能只在角落贴名称或 Logo。无明确来源时不补造身份。

## 套图一致性

共享笔触、字体性格、颜色角色、人物世界和线条密度，不共享完成后的构图模板。不同图片应根据认知目标改变主场景、动作方向、焦点尺度和文字—对象关系。

禁止多数图片重复“顶部标题 + 中间人物/图标网格 + 底部摘要”。重复角色只有在动作、处境或关系随叙事推进时才可复用。

## 文字规则

- 使用与输入相同的语言，除非用户另有指定。
- 精简信息，突出关键词、核心概念与必要数字。
- 所有文字、线条和图像保持统一的手绘质感。
- 主标题可在 5 秒内完整读完；正文不贴边、不跨越人物面部或复杂图形。
- 「参考图片内容」是唯一可读文字白名单；不生成白名单外文字。需要精确的名称、数字、命令或 URL 时逐字符保留。

## 视觉语言

- 手绘插画、轻微不规则轮廓、平涂或柔和纸感。
- 色彩由主题决定，控制主色与少量强调色，保证文字对比。
- 氛围轻松但不幼稚；技术主题也保持清晰和可信。
- 若内容涉及敏感、受保护或无法直接使用的人物形象，改用不复制具体肖像、但能承载相同叙事角色的原创替代形象。

## 禁区

- 禁止写实摄影、3D 写实物体或照片质感混入。
- 禁止密集图标、装饰性箭头、无意义贴纸和满版文字。
- 禁止用著名人物形象替代事实证据或制造未经来源支持的背书。
- 禁止让文字与图形、边框、裁切线互相覆盖。

## 自包含 Prompt 模板

把方括号内容替换为本图信息，并连同「参考图片内容」一起使用：

```text
请为「[主题]」创作一张 [比例与方向] 的手绘卡通信息图。读者看完应理解「[认知目标]」，核心主张是「[核心主张]」。使用 [输入语言]，准确呈现参考图片内容中的全部必需文字，不新增文字。有明确命名来源时，以次级层级逐字呈现来源标识「[最小来源标识]」，并用 [来源身份锚点] 延续来源名称或实体类型；无明确来源时不补造。以 [主场景] 为第一视觉焦点，让 [角色/对象] 通过 [关键动作] 解释 [信息关系]；若移除这一场景机制，读者应更难理解「[removal delta]」。使用至少两个内容解释锚点：[锚点列表]。用充足留白分开标题、主体和辅助说明，突出 [关键词/数字]。所有图像、文字、线条和图标统一为手绘插画质感，避免写实、3D、照片、密集装饰和无意义符号。使用 [主色/辅色]，保持清晰对比与 [氛围]。预留 [安全区]，确保任何文字不贴边、不被人物、图标或边框遮挡。不得表现 [事实禁区/误导性证据]，不得把来源标识做成无职责的固定页脚，也不得复用相邻图片的完成构图模板。
```
