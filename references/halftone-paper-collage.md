# Halftone Paper Collage Profile

内部 Profile 版本：2。来源：`KKenny0/project-promo-skill/references/halftone-paper-collage-system.md`。对外 Style 名称为 `Halftone Paper Collage`；版本号只用于维护规范，不得进入用户产物或生图指令。该 Profile 通过承载语义的编辑操作组织信息，不是“半调纹理 + 撕纸装饰”。

## 核心原则

先写 Card Responsibility Brief，再选择一个最小、真实、占主导的编辑操作，使信息关系更容易被识别。顺序是：认知目标与关系 → 来源身份和内容解释锚点 → 编辑操作 → 文字—物体联动 → 材质细化。

若移除裁切、折叠、遮罩、重叠、接缝或空间关系后，理解与记忆成本没有明显上升，则该操作只是装饰，必须重做。

## 关系到操作的映射

| 信息关系 | 候选编辑操作 | 应更容易感知的内容 |
| --- | --- | --- |
| 包含 | 裁入、口袋、留白框定、归档 | 什么留在边界内 |
| 转化 | 裁切、折叠、穿过平面、重新套印 | 什么改变、什么保留 |
| 边界 | 撕开、分离、中断、跨接缝保持 | 默认、可选、排除或独立控制 |
| 比较 | 并置、镜像、对齐、错位、暴露 | 真正产生后果的差异 |
| 顺序 | 按来源顺序重叠、揭示、连续裁切 | 有依据的推进次序 |
| 分组 | 聚拢、堆叠、钉住、分类、索引 | 为什么属于同一组 |
| 尺度 | 强裁切、放大片段、压缩场域 | 相对重要性或范围 |
| 选择 | 有依据地分支、拆标签、暴露选项 | 选择权或分歧所在 |

没有事实依据时，不得用路径、分支、层级、进度轴或比例暗示不存在的流程和数量关系。优先用间距、裁切、遮罩和重叠表达。

## 来源身份与内容解释锚点

生图前区分两类已验证锚点。有明确命名来源时记录至少 1 个名称之外的来源身份锚点，并为本图记录至少 2 个内容解释锚点；无明确来源时不补造身份：

- 来源身份锚点：经核验的实体类型，以及与该类型相符且有来源依据的材料、结构、行为或可核查资产；规范名称由最小来源标识承担，不单独计入锚点数量；
- 内容解释锚点：来源术语、工作流对象、因果对象、经过验证的结构、公式形态或证据形式；
- 两类锚点共同建立“它是什么、叫什么、讲什么”，但身份始终保持次级，不替代主导编辑操作。

书页、书脊、章节页签、论文批注、产品边界等只作为实体类型相关的候选机制，不是固定映射。泛化的复古手、办公用品、报纸、文件夹、屏幕、箭头、GitHub Logo 和科技符号不能单独构成来源身份。

## 材质与构图

- 全套共享一个受控纸张世界：按用户指定、可核查来源视觉、平台环境、内容语气与文字对比选择背景纸和主色场，使用最多两种有语义角色的卡纸强调色、克制阴影与受控纸张颗粒。纸张可以是冷白、亮白、灰色、彩色或深色，不默认暖米白和复古泛黄。
- 半调只用于照片或插画剪影，并确保目标尺寸下网点仍可辨识。
- 一张图只设一个主导操作簇，并保留足够负空间。
- 纸片必须是带有对象、状态、边界或解释职责的“编辑片段 / 语义模块”，不是旋转过的通用内容卡。
- 完整矩形纸板只有在边界能保留对象身份、状态、包含、比较、流程角色或证据上下文时才成立。
- 空白必须保护可读性、制造必要停顿、暴露裁切或维持状态辨识；否则缩减材料。

## 文字与物体联动

- 标题必须参与同一编辑操作：由边缘承托、跨越有意义的裁切、与转化对齐、随关系改变场域，或作为开放文字自然进入解释模块。
- 主张仍须在一次自然扫描中完整、可读；不得遮住关键字形或让读者跨无关空白拼句。
- 短标签直接附着在它解释的对象、接缝或边界上。
- 若把标题移回普通顶部标题栏而不损失理解或张力，说明文字仍是悬浮覆盖层，需重新整合。
- 有明确依据的连接线必须从语义模块的边缘端口出发，走在模块下方或外部间隙中，不得穿过文字、填充、轮廓或可感知阴影。

## 资产与证据边界

- 优先使用来源衍生的矢量几何、项目资产、确定性形状和独立剪影层。
- 「参考图片内容」是唯一可读文字白名单。未逐字提供的终端、代码、命令、状态列表、编号和 UI 文案必须留白、抽象为不可读纹理或删除。
- 生成资产只能解释定性转化、机制、比较或边界；不得伪造 UI、输出、代码、命令、数字、Logo、水印、产品结果或可读证据。
- 截图只有在回答真实读者问题且内容可核查时才使用，并与生成或处理过的图层分离。
- 每个资产声明角色：解释 / 身份 / 注意 / 证据；同时声明来源、处理边界与禁止被读成什么。

## 套图一致性

共享纸张、半调处理、颜色角色、光线和来源身份连续性，不共享完成后的构图句子。不同图应根据各自关系改变内容解释锚点、裁切、密度、拓扑、焦点尺度、文字—物体关系和主导操作。

生图前先把这些共享项具体化为 Suite Lock：唯一背景纸、参考色与选择依据；墨线/正文、主色场、最多两种强调卡纸的语义角色及可选参考色；纸张颗粒与半调网点密度；裁边/keyline；阴影方向、长度和强度；标题与正文字体性格。背景选择前在内部比较至少三个色温或明度明显不同的候选；不得因为 Style 是纸张拼贴就默认暖米白、羊皮纸或复古纸。每张图逐项完整重复这些固定值，只在「本图变化」中改变主导编辑操作、构图重心和既有强调色的使用比例。不得逐图更换纸张色族、颜色角色、网点体系、描边或光影。

禁止多数图片重复“顶部标题 + 中间物体 + 底部摘要/标签”。若交换相邻两图的主拼贴后两张仍同样易懂，说明资产只是气氛填充，必须重建。重复对象只有在状态、动作或关系随叙事推进时才可复用。

同层级文字保持一致的字体性格，不要求模型复刻具体字体名称。中性比较必须保持两侧视觉权重中立，不得用饱和度、明暗、尺寸或材质精致度提前编码赢家与输家。

## 禁区

- 半调背景后叠放不变的标题、列表或截图。
- 泛复古手、贴纸、星星、封印、报纸和无关几何只为填空。
- 纸片仅靠撕边、倾斜、阴影或越界伪装成语义片段。
- 复用同一个居中剪影、页脚标签、标题区或完整拼贴。
- 生成层冒充产品证据、真实 UI、精确数字或来源材料。
- 连接线进入文字区、纸片轮廓或阴影边界。
