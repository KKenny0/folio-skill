# 三产物契约

完整内容套件只交付 `publish-info`、`article-draft`、`figure-spec`。内部规划、事实核查记录和 QA 记录不得成为第四份用户产物。只有用户使用“只要”“不要”“无需”“仅输出”等明确限定或排除措辞时，才缩小交付范围；仅列出文章与配图等所需内容，不视为排除未点名的默认产物。

事实链固定为：

```text
原始来源 → article-draft → publish-info / figure-spec
```

`article-draft` 是规范内容事实源。完整套件中它是用户可见产物；用户明确排除它时，仍在内部生成并核查，但不交付。标题和简介中的事实性主张，以及 `figure-spec` 的图上文字、核心主张和事实性视觉关系，都必须能在文章中逐字或等义定位。图中分类、步骤、按钮、卡片和示意物的可读标签同样属于图上文字；文章没有具体条目时，必须使用无文字示意物，不能为方便构图补造示例。原始来源只直接证明文章。

## 1. publish-info

职责：提供发布元数据，不承载正文或逐图脚本。

```markdown
### 📋 publish-info

**标题**：[一行可读的标题]
**简介**：[一个短段落]
**标签**：[平台分类 1] · [平台分类 2] · [平台分类 3]
```

- 用户或平台给出长度限制时服从；未给出时标题保持一行可读，简介保持一个短段落。

### 标签规则

- 输出 2–3 个标签，语言与发布内容一致。用户或平台提供受控分类时，从该范围内选择；没有受控分类时动态推荐。
- 标签是面向社交媒体平台的编辑分类，可以从内容类型、所属领域、目标受众、内容形式或项目属性等角度形成，但不要求机械地每个维度各选一个。
- 每个标签必须是可复用于多篇同类内容的简短分类名，与文章整体定位一致；标签不属于文章事实链，不要求在正文逐字或等义出现。
- 不得使用当前内容中的唯一实体名，包括项目名、产品名、人物名、组织名或文章标题。通用领域术语（例如 `AI Agent`）可以是领域分类，具体项目名不可以。
- 不得把具体机制、功能描述、结论、动作或正文短语缩写成标签；不得使用完整句子或摘要式短语。
- 不得使用数字效果、排名、虚假背书或无法验证的营销结论；2–3 个标签之间不得是同义改写或明显重复分类。

## 2. article-draft

职责：完整、可独立阅读和发布的文章，也是其他两份产物的唯一内容事实源。

```markdown
### 📝 article-draft

# [文章标题]

[导语：主题、问题与价值]

## [自然章节标题]
[完整正文]

## 来源与核查

- 来源：[URL 或文件名；没有则写“未提供可核查来源”]
- Revision / 访问日期：[可用值；没有则写“未提供”]
- 核查日期：[日期]
- 不确定性：[已知边界]
```

- 按主题逻辑组织，不按图片顺序组织。
- 禁止出现总图数、图号、逐图文案、构图、颜色、材质或生图指令。
- 个人判断必须明确为判断，不得伪装成来源事实。
- 项目或工具文章必须帮助读者判断相关性、机制和实际使用方式、证据可信度、采用成本、限制、best-fit、not-fit 与最低成本下一步。

## 3. figure-spec

职责：把文章转化为配图叙事；用最小审校摘要帮助用户核对，以每张图的完整 Prompt 作为视觉执行源。

`article-draft` 决定什么内容可以说；「完整生图指令」决定该图如何生成。「参考图片内容」「本图任务」「视觉方案与事实边界」只是 Prompt 的可读索引，不得拥有 Prompt 中不存在的独立执行约束。文件头只输出套图设置、统一视觉系统和生成交接；任取一条完整 Prompt 都必须能脱离文件头和其他图片直接进入视觉生产。

```markdown
### 🎨 figure-spec

**套图设置**：Style：[规范 Style 名称；不包含内部 Profile 版本]；选择方式：[用户指定 / 自动路由]；路由理由：[所选媒介的表达优势 + 关键视觉机制 + 另一种 Style 所需的额外转换]；发布场景：[平台或内容场景]；覆盖策略：[选择性提炼 / 主要章节完整映射]；统一比例：[比例与方向，同时写明宽:高]；建议画布：[与比例严格等比的宽×高像素；3:4 竖版使用 1536×2048 px]。
**统一视觉系统**：背景基底：[名称 + 可选参考色]；选择依据：[背景职责 + 用户/来源/平台/密度或内容结构证据 + 为什么胜过最接近的候选；不得只写 Style 名称或泛化情绪词]；颜色角色：[墨线/正文、主色、辅色、强调色及各自语义，可选参考色]；材质与纹理：[固定值]；线条与笔触：[固定值]；光影：[固定值]；字体性格：[固定值]；连续性：[Hand-Drawn 的插画对象及适用的人物世界，或 Halftone 的纸张/网点世界；不适用项写明具体边界]。背景选择前在内部比较浅色功能底、彩色场、深色或材质底三个明显不同的候选家族；不输出候选，只输出最终值与紧凑依据。参考色只用于跨工具锚定视觉家族，不承诺像素级一致。
**生成交接**：支持 Aspect Ratio、Canvas Size 或 Width/Height 的工具显式设置目标比例或画布且不使用 Auto；prompt-only 工具原样使用完整 Prompt，但 Prompt 不能覆盖工具固定比例。支持参考图时，可先生成图 1，再让图 2+ 以图 1 作为风格参考，只继承媒介、颜色渲染与重复对象造型，不继承图 1 的构图或文字；当前图的文字白名单和 Prompt 始终优先，参考图不是内容证据。不支持参考图时直接使用 Suite Lock + Prompt。参考图和 Prompt 只能提高遵循率，不代表成图文字或构图已经通过；成图仍须单独做 Bitmap QA。成图有误时先修正 Prompt 再重新生成，不得用程序覆盖位图文字。

## 图 1

### 参考图片内容
- 主标题：[实际文字；没有则写“无”]
- 副标题：[实际文字；没有则写“无”]
- 正文 / 列表：[逐行列出；没有则写“无”]
- 强调词 / 数字：[实际文字；没有则写“无”]
- 必要署名 / 限制：[有明确命名来源时写“规范名称 · 实体类型”，其中实体类型必须有来源支持；只加入确实必须显示在图上的其他限制。文章的来源、核查日期和不确定性尾注留在 article-draft 或禁区事实边界，不自动复制到图上；都没有则写“无”]

### 本图任务

[位置角色：入口 / 展开 / 判断 / 收束；认知目标；核心主张；信息关系。用一个短段落表达，不新增文章外事实。]

### 视觉方案与事实边界

- 视觉方案：[构图机制；来源身份锚点；至少两个内容解释锚点；本图允许变化；文字层级与安全区。]
- 事实边界：[不可出现的误导性元素、证据、主张或白名单外文字。]

### 完整生图指令

[合并本图全部执行约束、可直接复制生图的完整 Prompt。]
```

图号统一使用阿拉伯数字 `## 图 1`、`## 图 2`，不写“图一”“图二”。

每条完整 Prompt 都重复完整 Style、画幅、建议画布、语言、文字、构图、统一视觉系统全部固定值、本图允许变化、两类锚点、安全区与事实边界。统一视觉系统按背景、选择依据、颜色角色、材质、笔触、光影、字体性格和连续性逐项核对；自然语序可以不同，但任何固定值都不得遗漏、改义或被本图变化覆盖。有明确命名来源时，Prompt 必须逐字包含「必要署名 / 限制」中的最小来源标识，并把来源身份锚点与内容解释锚点共同融入画面；身份标识保持次级，不得成为统一页脚模板。审校摘要中的任务、视觉方案和事实边界必须都能在 Prompt 中定位；发生冲突时修正 Prompt 与摘要后再交付，不能把摘要当成第二套执行指令。

「参考图片内容」是唯一允许与 Prompt 重复的逐字内容，因为它承担文字白名单职责。图中分类、步骤、按钮、卡片和示意物的可读标签同样属于白名单；文章没有具体条目时必须使用无文字示意物。任取一条 Prompt 都不能引用“同上”“沿用前图”、文件头或其他图片；删去任一张图不得破坏其他图片的可执行性。

套图阅读动力来自内容顺序而不是互动诱导。入口图可以建立文章已有的真实问题、来源或价值；展开图解释机制；判断图呈现成本、限制或适用边界；收束图给出结论或文章支持的最低成本下一步。不是每套都必须包含全部角色。默认不得添加“下一页更精彩”、无依据最高级、FOMO、虚假社会证明、收藏、关注、转发或评论文案，也不得为翻页隐藏重要限制。用户明确提供的非事实型 CTA 可以在先纳入文章后按原文派生；数字、效果、普及度和背书仍须有来源支持。

完整生图指令必须以以下句式开头，其中比例、方向和像素取本图实际值：

```text
【最高优先级画布约束】从一开始就在严格的 [比例] [方向] 画布中构图，宽:高 = [比例]，建议画布 [宽×高 px]。不得生成与目标不一致的比例，不得先按其他比例构图后再裁切。
```

目标为 3:4 竖版时，开头追加“不得生成 2:3、4:5、1:1 或横版画布”。指令最后必须以以下句式收束：

```text
最终输出必须保持严格的 [比例] [方向] 画布；所有文字、主体和安全区均按该画布原生布局。
```

比例是规范目标，像素是跨工具建议值。不得在同一套图中出现冲突比例、方向或非等比像素，也不得声称 Prompt 能覆盖下游工具固定的输出比例。颜色参考值同样只提高跨工具的一致性：验收目标是相同背景色族、颜色语义、材质、笔触与光影系统，不是不同工具的像素完全相同。Hand-Drawn 与 Halftone 都不自带默认背景色；暖米白可以因用户指定、来源纸本视觉、档案/手账/出版语义或明确的亲密叙事胜出，但不能只用“手绘感”“纸张感”“亲和”“好看”解释。不得为追求多样而逐图换底、随机选色或维护跨套配额。参考图只提供视觉锚定，不得成为事实来源；若参考图导致标题串图、宏观构图复制或新旧 Prompt 冲突，停止使用参考图并回退到 Suite Lock + Prompt。

`figure-spec` 可以压缩、重组或选择性提炼文章，但不得引入文章中没有的事实。删去任一张图不得破坏其他图的可执行性。
