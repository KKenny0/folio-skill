# Style Router

先确定发布场景、覆盖范围和每张图要产生的认知变化，再选择视觉语言。Style 规定媒介语法，不规定必须出现人物、对象或某种背景色。配图中的事实性文字和关系必须先写入 `article-draft`；Style 只能决定如何画，不能补充事实。

## 优先级

1. 用户明确指定任一受支持 Style：直接采用，不自动改写；其他 Style 按 `SKILL.md` 的支持范围处理，不生成临时 Profile。
2. 用户未指定：按连续手绘表达还是离散纸片组装更能自然覆盖整套内容来自动选择，并在 `figure-spec` 开头说明理由。
3. 同一套图只用一种 Style。用户明确要求混用时，请其选择一种，或把内容拆成两套并分别建立 Suite Lock；不得在同一套图内逐图路由。

## 自动选择

| 判断信号 | Hand-Drawn Infographic | Halftone Paper Collage |
| --- | --- | --- |
| 媒介语法 | 连续手绘线条、平涂或笔刷、自由注释 | 离散纸片、裁切、层叠、接缝与半调 |
| 自然优势 | 对象演示、手绘流程、注释图、连续空间、类比或动作 | 边界、包含、分层、并置、替换、裁切或状态块 |
| 内容载体 | 对象、符号、环境、空间、手或人物均可 | 纸片、剪影、容器、边界、层次与组装关系 |
| 失败风险 | 退化为随手线稿、人物装饰或图标网格 | 退化为半调背景、泛复古拼贴或重复卡片模板 |

不要按“有人 / 无人”“技术 / 非技术”或“步骤 / 比较”等标签分类；同一内容关系可以用两种 Style 表达。先为整套而不是单张判断：

1. 若多数卡片能用连续线条、对象演示、自由注释、手绘流程或连续空间直接表达，且不需要把内容强行拆成纸片，手绘候选成立。人物只在人物处境或真实动作本身承载主张时使用。
2. 若多数卡片必须通过离散单元、边界、层次、包含、裁切、并置或组装转化才能清楚表达，拼贴候选成立。
3. 只有一个候选成立时，选择该 Style；两者都不成立时，重做 Card Responsibility Brief，不用 Style 掩盖内容规划不足。
4. 两者都成立时，分别写一句覆盖整套的候选 storyboard，选择需要更少人为拆分、装饰性人物或抽象纸片的一种。采用判断、比较、系统解释等题材名称不得充当平局规则。

人物、背景和配色均不参与 Style 的硬判定。人物可以出现在两种 Style 中，也可以完全不出现；背景与颜色由 Suite Lock 独立选择。不得为平衡两种 Style 的出现次数而轮换或随机选择。

## 覆盖范围

- 社交媒体、公众号多图轮播或推广套图：选择性提炼 4–6 个最值得视觉化的信息点；允许合并章节。
- 教程、报告、系统解释或用户要求完整覆盖：主要章节均须至少映射到一张图；可以增加图数。
- 无法判断发布场景时：按社交媒体多图轮播处理，并明确这是默认假设。

来源身份与 Style 正交：Style 决定如何解释内容，来源身份决定这些图属于什么实体。对有明确命名来源的套图，首图建立规范名称、可验证实体类型与主题；每张内页延续“规范名称 · 实体类型”这一最小来源标识，整套至少使用两种身份表达方式，例如文字署名与实体类型相符的材料、结构或行为线索。实体类型必须有来源支持；身份线索保持次级，不得替代本图的认知目标或主导视觉机制。文章核查尾注不属于来源标识；无明确来源时不补造身份。

先在内部建立 Card Responsibility Brief，不输出为独立文件：

- 套图位置角色：入口、展开、判断或收束；不是每套都必须包含全部角色；
- 信息密度：入口与收束默认低密度，展开与判断按内容选择平衡、清单、比较或流程；
- 本图唯一认知目标；
- 核心主张；
- 信息关系；
- 必须出现的文字；
- 来源身份锚点；
- 内容解释锚点；
- 事实与证据边界；
- 空白区域的责任；
- 与前后图片的自然推进关系；该关系只决定顺序，不得成为单图理解前提。

套图阅读动力必须来自内容本身：入口建立文章已有的真实问题、来源或价值，展开解释机制，判断呈现成本、限制或适用边界，收束给出结论或文章支持的最低成本下一步。不得自动添加“下一页更精彩”、无依据最高级、FOMO、虚假社会证明、收藏、关注、转发或评论诱导；不得为制造翻页动机隐藏应当立即说明的重要限制。用户明确要求非事实型 CTA 时按原文处理并先纳入 `article-draft`；涉及数字、效果、普及度或背书的 CTA 仍须有来源支持。

## 背景职责

背景不是 Style 的默认皮肤。先决定它在整套图中承担什么职责，再选择颜色与表面：

- 阅读底：承载高密度文字、命令或步骤；
- 结构底：让边界、层级、路径或比较关系显形；
- 聚焦底：让单一对象或判断成为第一焦点；
- 情绪底：建立与文章一致的克制、轻松、紧迫或反思状态；
- 来源底：延续用户指定或可核查来源的视觉身份。

内部必须比较三个明显不同的候选家族，不输出候选过程：

1. 浅色功能底：冷白、浅灰或低彩浅色；
2. 彩色场：有语义职责的低饱和或高对比彩色平涂；
3. 深色或材质底：深海军蓝、炭灰、彩色纸、暖米白纸等。

三个近似浅暖色不构成三个候选。按“用户指定 → 可核查来源视觉 → 平台环境 → 信息密度与可读性 → 背景职责”选择；仍并列时选语义更具体、对核心关系帮助更直接的一项，不靠随机或跨套颜色配额破平。信息密度只设可读性门槛：高密度通常需要稳定对比，但不等于必须米白；低密度必须认真比较彩色场或深色聚焦底，但不强制使用深色。

暖米白是正常候选。用户明确指定、来源具有纸本视觉、内容确有档案/手账/出版语义或需要亲密的纸面阅读距离时，它可以胜出；“手绘感”“纸张感”“亲和”“好看”不能单独作为选择证据。最终「选择依据」只输出一句紧凑结论：背景职责 + 内容证据 + 为什么胜过最接近的候选。同一套锁定一个背景家族，不逐图换底；Style 仍只决定媒介语法。

## 画幅

优先级：用户指定 > 发布平台要求 > Folio 默认。画幅与 Style 解耦。

- 没有用户或平台要求时，两种 Style 均默认 `3:4` 竖版，建议画布 `1536×2048 px`。
- 同一套图统一比例与建议画布；每条完整 Prompt 仍需重复写明比例、方向和像素值。
- 用户或平台指定其他比例时，建议画布的宽高比必须与目标比例严格相等。不得把工具的常见默认尺寸当作近似值，例如 3:4 不能写成 `1024×1536 px`，因为后者是 2:3。
- 若下游工具提供 Aspect Ratio、Canvas Size 或 Width/Height 设置，要求用户显式设置目标值且不使用 Auto；只有 prompt 输入时，保留完整画布约束，同时明确这只能提高遵循率，不能覆盖工具固定比例。

自动路由理由必须写成“整套主要依赖 `[连续手绘表达 / 离散纸片组装]`；选择 `[Style]` 可以直接呈现 `[关键视觉机制]`，而另一种 Style 需要 `[额外的人为转换]`”。不能只写“有人所以手绘”“更适合技术内容”“信息关系是比较”或“更有设计感”。
