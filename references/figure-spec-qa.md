# Figure Spec 生图前 QA

只检查规格，不生成图片，也不替代 Bitmap 后验 QA。`article-draft` 是内容事实源，每条「完整生图指令」是视觉执行源；「参考图片内容」「本图任务」「视觉方案与事实边界」只承担审校职责。先逐图检查，再检查整套；任一硬失败都必须修正后重检。

## 严重级别

- `FAIL`：事实越界、文字白名单或完整 Prompt 缺失、审校摘要与 Prompt 冲突、Prompt 缺少 Style/画幅/建议画布/语言/统一视觉系统/构图/安全区/事实边界、比例与像素冲突、依赖全局上下文、文字不可读、虚假证据、错误视觉关系或自动添加互动诱导。
- `WARN`：信息偏密、层级弱、构图重复、留白职责不清、Style 机制不足，或条件式参考图可能造成版式复制。
- `PASS`：内容可追溯、摘要可审校、Prompt 自包含且可直接生图。

最终 `PASS` 是硬门槛：必须为零个 `FAIL`，且每个 `WARN` 都已经修正或以可核查证据说明不构成风险。不能用“整体可用”覆盖单图失败。

## 可重复执行的硬门槛

先把每个 `## 图 N` 到下一张图之前的内容视为一张任务包。审校时可以读取文件头核对套图一致性，但必须单独复制「完整生图指令」验证其不依赖文件头或其他图片。

| 门槛 | 通过条件 | 失败证据 |
| --- | --- | --- |
| 文件头结构 | 只有「套图设置」「统一视觉系统」「生成交接」三个区块，且都有实际值 | 保留分散的逐项声明、缺少任一区块或含占位符 |
| 单图结构 | 图号使用阿拉伯数字 `## 图 N`，并同时存在「参考图片内容」「本图任务」「视觉方案与事实边界」「完整生图指令」 | 使用“图一”等其他编号；任一区块缺失；或继续输出旧「配图规格」字段清单 |
| 实际文字 | 主标题及所有正文、强调词、限制逐项写明；没有则明确写“无” | “见上文”“同上”“略”或白名单外可读文字 |
| 摘要—Prompt 一致 | 位置角色、目标、主张、关系、构图、两类锚点、本图变化、安全区与事实边界均能在 Prompt 中定位，含义相同 | 摘要拥有 Prompt 中没有的执行约束，或两者冲突 |
| 自包含 Prompt | Prompt 独立包含 Style、画幅、建议画布、语言、全部文字、构图、两类锚点、Suite Lock、本图变化、安全区与事实边界 | 依赖文件头、参考图或其他图片补齐任何执行信息 |
| 画布数学一致性 | 建议画布的宽:高与目标比例严格相等；3:4 默认值为 1536×2048 px | 3:4 搭配 1024×1536 px，或任何近似、冲突比例 |
| Prompt 画布边界 | 以最高优先级画布约束开头、以原生画布收束句结尾 | 缺少首尾约束或声称 Prompt 可覆盖工具固定比例 |
| 下游执行 | 支持比例参数时显式设置且不使用 Auto；不支持参考图时可退化为 Suite Lock + Prompt | 只依赖 Prompt、强制要求参考图，或没有退化路径 |
| 参考图边界 | 只继承媒介、颜色渲染和重复对象造型；当前白名单和 Prompt 优先；参考图不是事实来源 | 继承图 1 的文字、宏观构图、事实或未声明对象 |
| 修正路径 | 成图有误时修正 Prompt 并重新生成 | 用程序覆盖、擦除或替换位图文字来伪装修复 |
| 路由依据 | 自动路由理由说明媒介优势、关键机制与另一种 Style 所需的额外转换 | 只写人物有无、题材、信息关系或“更有设计感” |
| 背景路由 | 选择依据说明背景职责、内容证据及相对最接近候选的优势；内部候选覆盖浅色功能底、彩色场、深色或材质底 | 三个候选都是近似浅暖色；只写“手绘感”“纸张感”“亲和”“好看”；或来源视觉被通用米白覆盖 |
| 来源身份 | 规范名称、实体类型和身份锚点可回溯；每条 Prompt 保留最小来源标识和至少一个来源身份锚点 | 只有首图可识别、只重复页脚、或推断未经证实的身份 |
| 视觉系统 | 文件头给出具体背景及依据；每条 Prompt 完整继承颜色角色、材质、笔触、光影、字体与连续性 | Prompt 遗漏固定值、换背景色族、颜色换义或引入新媒介 |
| 内容原生推进 | 位置角色和顺序由真实问题、机制、限制、判断或下一步推动；单图仍独立可懂 | 自动添加翻页诱导、FOMO、无依据最高级、虚假社会证明或隐藏重要限制 |
| CTA 边界 | 默认无收藏、关注、转发、评论文案；用户明确要求的非事实型 CTA 先进入文章再按原文派生 | 自动补 CTA，或把数字、效果、普及度、背书写成无来源 CTA |
| Style 专项 | 手绘有明确内容载体与至少 2 个解释锚点；半调有主导编辑操作、关系、至少 2 个解释锚点、文字—物体联动与 removal delta | 只有名称、风格形容词、纹理、泛化人物或泛化图标 |

字段检索只能证明结构存在。事实边界、阅读动力是否内容原生、视觉机制是否承担解释、摘要与 Prompt 是否等义，仍需逐图人工判断。

## 逐图检查

1. **事实边界**：主张、数字、公式、名称、命令、URL、限制和全部可读标签均能追溯到 `article-draft`；「参考图片内容」是唯一可读文字白名单。白名单外的代码、命令、UI、ID、编号和状态文案必须留白、不可读或删除。
2. **文字白名单**：主标题、正文、强调词与必要限制完整明确，并在 Prompt 中逐字出现；Prompt 不得新增可读文字。
3. **本图任务**：用一个短段落说明位置角色、唯一认知目标、核心主张与信息关系；角色只决定套图顺序，不得成为理解前提。
4. **视觉方案**：明确构图、至少一个有来源依据的来源身份锚点、至少两个内容解释锚点、本图变化和安全区；无明确来源时身份锚点写“无明确来源”，不得补造。
5. **摘要—Prompt 同步**：摘要是 Prompt 的索引，不是第二套执行指令；任何摘要内容在 Prompt 中缺失、改义或冲突都标记 `FAIL`。
6. **自包含性**：单独复制 Prompt 时，仍有 Style、画幅、建议画布、方向、语言、文字、目标、关系、构图、锚点、视觉系统、本图变化、禁区和安全区。规范英文 Style 名称不作为 Prompt 风格前缀；内部 Profile 名称与版本号不得进入产物。
7. **来源身份**：有明确命名来源时，「必要署名 / 限制」与 Prompt 逐字包含“规范名称 · 实体类型”；执行 Recognition Test 与 Generic Substitution Test，且不得为通过测试补造来源没有的 Logo、资产或特征。
8. **文字负载**：主张 5 秒内可扫读；无法在目标画幅留出合理字号与行距时，先压缩文案或拆图。
9. **比例与视觉系统**：Prompt 首尾画布约束一致，建议画布严格等比；完整继承文件头的背景及依据、颜色角色、材质、笔触、光影、字体和适用连续性，只在本图变化范围内调整。逐色列出本图承载对象并与 Suite Lock 对账；面积可以变化，语义不得变化。
10. **背景职责**：背景必须实际帮助阅读、结构、聚焦、情绪或来源身份；高密度只提高对比要求，不自动等于米白，低密度必须比较彩色场或深色聚焦底但不强制选用。
11. **Style 参与表达**：手绘移除对象关系、注释、状态变化、动作或空间组织后，理解应明显受损；半调移除边界、层次、裁切或组装操作后，理解应明显受损。
12. **数量完整性**：文案明确有 N 个步骤、层级、类别或状态时，构图提供 N 个可辨识位置，不遗漏、合并或增加。
13. **禁区与互动边界**：禁止假截图、假数据、假背书、假流程、受保护肖像复制、多余文字，以及未由用户明确要求或文章支持的 FOMO、最高级、社会证明、翻页钩子和 CTA。

## 整套检查

1. 只使用一个已选 Style；混用请求必须先选择一种，或拆成两套分别建立 Suite Lock。
2. 所有 Prompt 的比例、建议画布、语言与统一视觉系统一致；没有背景色族漂移、颜色换义、媒介变化或重复对象造型漂移。
3. 首图建立名称、可验证实体类型与主题；每张内页保留最小来源标识，整套至少结合两种身份表达方式，不退化为统一页脚。
4. 社交媒体套图提炼 4–6 个高价值信息点；教程或报告覆盖全部主要章节。
5. 位置角色形成自然的“入口 → 展开 / 判断 → 收束”推进，但不是每套都必须包含全部角色；任何单图仍可独立理解。
6. 相邻图片不重复同一标题位置、中心物体、页脚标签、围合深度和密度；多数图片重复“顶部标题 + 中间主体 + 底部横条”标记 `FAIL`。
7. 半调套图复用视觉词汇而非完成拼贴；交换相邻主构图后若仍同样易懂，标记 `FAIL`。
8. 所有认知目标互补；中性比较的两侧保持视觉权重中立，不暗示来源没有的优劣。
9. 若「生成交接」建议首图参考链，必须同时声明条件、继承范围、Prompt 优先级和无参考图退化路径；不得声称参考图能保证一致性，也不得把 Prompt 或参考链通过写成成图已通过；成图仍须单独做 Bitmap QA。
10. 全套只锁定一个背景家族；不得为制造多样性逐图换底，也不得用随机或跨套颜色配额替代内容判断。
