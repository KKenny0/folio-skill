# Visual Mechanism Router

Folio 的 Style 固定为 `Folio Editorial Sketch`，不再选择媒介风格。视觉路由只决定每张图用什么关系机制解释内容；所有机制都必须通过同一 House Lock 渲染。

## 决策顺序

1. 先确定发布场景、覆盖范围和每张图要产生的认知变化。
2. 先写一句无需术语即可理解的读者结论，再把它改写成“主体—动作—对象”的视觉句子；为每张图建立 Card Responsibility Brief，锁定唯一认知目标、核心主张、主信息关系、白话职责标签、从属技术证据、文字白名单、来源身份锚点、内容解释锚点、事实边界与空白责任。
3. 先选择主手绘机制，再判断是否确实需要一个纸片操作簇；最后决定半调局部职责和陶土橙强调面积。
4. 在整套层面检查宏观构图轮廓不重复，并建立只包含内容变量的 Suite Lock。

## 信息组织门

视觉机制必须先让读者理解结论，再让术语证明结论：

1. **先白话，后术语**：标题、白话职责标签与主关系独立构成完整解释；字段、参数、代码和专有名词只能作为紧邻对应对象的次级证据。
2. **视觉句子**：每张图只有一个主要“主体—动作—对象”关系。画面中的位置、连线、边界或状态变化必须直接对应这句话。
3. **关系类型不混用**：职责分工、并列机制和对照主张使用明显分区、并列对象或分叉；只有内容核心明确支持先后依赖时，才使用一条连续路径表达整张图。
4. **标签就地归属**：职责标签贴近其负责的对象或区域，不能用漂浮术语和任意箭头让读者猜归属。
5. **白话隐藏测试**：遮住所有技术字段、参数、代码和英文术语后，只看标题、白话标签与主关系，读者仍应能在 5 秒内复述本图结论；否则先重写视觉句子，不进入机制选择。

若一张图同时包含多个必要关系，指定一个主关系，其余关系降为次级证据；无法建立明确主次时拆图。

## 主机制选择

| 读者需要看懂什么 | 优先主机制 | 纸片只在何时介入 |
| --- | --- | --- |
| 对象是什么、如何工作 | 对象演示、注释图、剖面 | 需要开窗、遮罩或承托一个真实边界 |
| 先后顺序或行动推进 | 连续路径、对象状态变化 | 需要明确阶段门槛、转折或终点 |
| 原因如何产生结果 | 前后对象、穿越关系、状态差异 | 需要显示什么被保留、遮住或转换 |
| 两者差异或选择后果 | 并列对象、分叉线、中立对照 | 需要同权重承托区或显式边界 |
| 什么在内、什么在外 | 开闭轮廓、线条状态变化、空间内外 | 裁入、缺口、口袋或分隔带能降低理解成本 |
| 部件如何归属或连接 | 聚拢连线、嵌套空间、手绘剖面 | 一个堆叠或聚合操作能显示层级 |
| 最终判断或下一步 | 路径汇入结论、对象落位 | 强调色结论区能承载行动而不是装饰 |

同一信息关系可以有不同构图。不要按技术/非技术、有人/无人、步骤/比较等题材标签机械决定机制。若找不到能直接解释主张的手绘关系，先重做 Card Responsibility Brief，不用纸片或人物掩盖内容规划不足。

## 覆盖范围

- 精确图数只接受 `1–12` 的正整数。零、负数、小数或互相冲突的多个精确值先澄清；超过 12 张时请用户拆批或缩小范围。
- “3–5 张”“至少 3 张”“至多 5 张”是范围约束，不是精确值。能根据覆盖范围在约束内确定单一数量时明确告知所选值；否则先澄清。
- 用户明确且合法的精确图数时严格服从该数量；`4–6` 张只是在用户未指定图数时的社交媒体默认值。
- 用户未指定图数的社交媒体、公众号多图轮播或推广套图：选择性提炼 `4–6` 个最值得视觉化的信息点，允许合并章节。
- 教程、报告、系统解释或用户要求完整覆盖：主要章节至少映射到一张图，可以增加图数。若用户同时指定的图数不足以完整覆盖，在规划前请其选择放宽图数或改为选择性提炼。
- 无法判断发布场景时：按社交媒体多图轮播处理。

套图阅读动力来自内容本身：入口建立真实问题、来源或价值；展开解释机制；判断呈现成本、限制或适用边界；收束给出结论或内容核心支持的最低成本下一步。不是每套都必须包含全部角色。不得自动添加翻页诱导、FOMO、无依据最高级、虚假社会证明或收藏、关注、转发、评论文案。

## 来源身份

来源身份与视觉机制正交。有明确命名来源时，首图建立规范名称、可验证实体类型与主题；每张内页延续“规范名称 · 实体类型”最小来源标识，并使用至少一个有来源依据的材料、结构、行为或资产线索。规范名称不单独计入内容解释锚点；完整来源说明、核查日期和不确定性不进入最小来源标识。无明确来源时不补造身份。

可核查来源色只允许留在边界清晰、来源已核验的次级来源资产内部；该资产可以同时承担身份锚点。Card Responsibility Brief 必须为每张图选择互斥分支：`house-only` 明确没有来源色资产且所有锚点使用 House Lock 四色；`bounded-source-asset` 明确资产名称、作用边界、已核验精确色值、色值到元素的分配、不得外溢范围与不得由参考图继承。其他身份锚点仍使用 House Lock 颜色，不得改写背景、核心色板或颜色语义。

## Card Responsibility Brief

内部记录但不输出为独立文件：

- 套图位置角色：入口、展开、判断或收束；
- 信息密度与唯一认知目标；
- 一句无需术语即可理解的读者结论；
- “主体—动作—对象”视觉句子；
- 核心主张和一个主信息关系；
- 白话职责标签与从属技术证据；
- 必须出现的文字；
- 来源身份锚点和至少两个内容解释锚点；
- 主手绘机制和可选的一个纸片操作簇；
- 陶土橙承担的语义及面积变化依据；
- 互斥来源色模式：`house-only`，或带资产名、边界、精确色值、元素分配和不继承声明的 `bounded-source-asset`；
- 事实与证据边界；
- 空白区域责任；
- 与前后图片的自然推进关系；该关系只决定顺序，不得成为单图理解前提。

## Suite Lock

House Lock 已由 `folio-editorial-sketch.md` 固定，Suite Lock 不再选择背景、色板、材质、笔触、字体或光影，只确定：

- 来源身份锚点；
- 重复对象、必要人物或来源资产的造型连续性；
- 每张图不同的主机制和宏观构图轮廓；
- 陶土橙面积随本图语义变化的计划；
- 条件式参考图只可继承的媒介、House Lock 四色渲染和重复对象造型；不得继承次级来源资产的局部来源色。

## 画幅

优先级为用户指定 > 平台要求 > Folio 默认。画幅不改变 Style。

- 没有用户或平台要求时使用 `3:4` 竖版，建议画布 `1536×2048 px`。
- 同一套图统一比例与建议画布；每条完整 Prompt 重复比例、方向和像素值。
- 建议画布宽高比必须与目标比例严格相等，不使用近似尺寸。
- 比例分量与像素宽高只接受正整数；每个建议画布维度应在 `256–8192 px`，长边:短边通常不超过 `4:1`。只有可核查的平台硬性要求才可例外，超界且未核实时请求目标平台支持的规格。
- 下游支持比例或尺寸参数时显式设置且不使用 Auto；只有 Prompt 输入时说明约束只能提高遵循率，不能覆盖工具固定比例。
