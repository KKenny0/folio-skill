# Signal Pack v0.2 前向案例

在新的临时 Git 仓库中安装完整本地 Skill。每个案例使用独立的 `codex exec --ephemeral --skip-git-repo-check --sandbox read-only` 会话；Agent 可按 `SKILL.md` 条件读取完整 references。只提供对应案例的用户请求，不提供预期答案正文、Skill 名称或验收断言。结果记录在本次验收报告中，不把易过期的 PASS 快照提交进 Skill。

## 1. 完整内容套件

**用户请求**：

> 把下面短文写成公众号文章，并给我 4 张配图规格：某团队把每周的客服问题按主题归类。第一周有 18 个问题，第二周有 12 个；他们发现“登录失败”在两周都出现。团队决定先为登录流程补充帮助页，而不是宣称问题已经解决。

**期望触发**：触发 Signal Pack，默认交付三产物。

**断言**：有 `publish-info`、`article-draft`、`figure-spec`；每张图的事实性文字都能在文章中逐字或等义定位。

**失败条件**：缺少任一产物，或图中出现文章没有的数字、因果、结果或主张。

## 2. 项目采用决策

**用户请求**：

> 用 https://github.com/RealKai42/qwerty-learner 写一套项目推荐文章和 4 张配图规格，帮助开发者判断是否采用。

**期望触发**：触发 Signal Pack；项目或工具内容一次生成采用决策型三产物。

**断言**：文章直接包含来源支持的 walkthrough、前置条件、限制、best-fit 与 not-fit；证据与编辑判断可区分；`publish-info` 和 `figure-spec` 与文章同步。

**失败条件**：先交基础版再要求升级，出现升级询问，或把 README 功能列表当成推荐文章。

## 3. 数字与公式保真

**用户请求**：

> 为下面内容制作一篇文章和 4 张配图规格：温度从 20 °C 升到 35 °C，变化量是 15 °C。面积公式为 A = πr²，半径 r 的范围是 2–4 cm。不要把单位或公式改写。

**期望触发**：触发 Signal Pack。

**断言**：文章与每张图中出现的数字、单位、范围和 `A = πr²` 完全一致。

**失败条件**：改变数字或单位，或以未声明的等价形式改写公式。

## 4. 负向触发

**用户请求**：

> 把下面内容整理成一篇学习笔记，不要配图：HTTP 缓存通过新鲜度和验证器避免不必要的重复传输。

**期望触发**：不隐式触发 Signal Pack。

**断言**：只按普通请求生成学习笔记，不输出 `publish-info` 或 `figure-spec`。

**失败条件**：调用 Signal Pack，或输出完整内容套件中的元数据或配图规格。
